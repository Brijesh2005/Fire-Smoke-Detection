How it works:

  • Captures frames directly from your webcam using HTML5 getUserMedia.
  • Sends frames securely to the local PyTorch inference endpoint (/api/predict/frame).
  • Instantly flags fire or smoke hazards with a pulsing visual alert and audible siren.
REST API Specification & Endpoints Integrate with cameras, IoT sensors, and external apps
GET /api/health

Returns model status, device, and PyTorch version. 

curl -X GET http://localhost:5000/api/health
POST /api/predict/image

Classifies an image via multipart form upload or JSON base64. 

curl -X POST -F "file=@test-imgs/image_0.jpg" http://localhost:5000/api/predict/image

Sample Response:

{
  "prediction": "Smoke",
  "confidence": 100.0,
  "is_hazard": true,
  "hazard_level": "WARNING",
  "probabilities": {
    "Fire": 0.0,
    "Smoke": 100.0,
    "Neutral": 0.0
  },
  "latency_ms": 95.2
}
POST /api/predict/video

Uploads a video file for frame sampling, event timeline, and hazard breakdown. 

curl -X POST -F "file=@sample.mp4" -F "sample_interval=0.5" http://localhost:5000/api/predict/video
Model Architecture ResNet-50 Deep Residual Network

The model leverages transfer learning on ResNet-50 pretrained on ImageNet.

Classifier Head:

  • Linear(2048, 128)
  • ReLU() activation
  • Linear(128, 3)
  • Softmax(dim=1) output across classes

Classes:

  • 🔴 Fire (Active flames, open fire)
  • 🟠 Smoke (Smoke plumes, early stage fire)
  • 🟢 Neutral (Normal ambient conditions, no fire)
